# ErgoStarter 🌿

### Better Posture. Smarter Setups. Budget-Friendly Workspaces.

ErgoStarter is a beginner-friendly platform designed to help students, interns, and entry-level remote workers build comfortable, functional, and ergonomic workspaces without spending excessively.

Our goal is to make ergonomic knowledge accessible through practical guides, affordable gear recommendations, and actionable workspace improvement tips.

---

## 🎯 Project Overview

Creating a comfortable workspace should not require an expensive investment. Many students and beginners experience discomfort due to poor desk setups, incorrect monitor positioning, inadequate seating, and improper posture.

ErgoStarter addresses these challenges by providing simple, practical, and budget-conscious solutions for building better workspaces.

**Our Core Focus:**
- Affordable ergonomic workspace solutions.
- Practical posture and comfort improvements.
- Beginner-friendly desk setup guides.
- Budget-friendly product recommendations.
- Accessible information for students and remote workers.

## 🚀 Getting Started

ErgoStarter is a static website and does not require backend configuration.

### Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/varshitfauzdar/ErgoStarter_SEO.git
```

**2. Open the project**

Open the cloned project folder in Visual Studio Code.

**3. Install Live Server**

Install the Live Server extension in VS Code.

**4. Launch the website**

Right-click `index.html` and select:

`Open with Live Server`

The website will open in your default browser.
